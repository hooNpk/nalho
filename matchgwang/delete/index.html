매치광 계정 삭제

매치광(개발자: 날호) · 개인정보 처리방침 · 매치광 소개

앱에서 바로 삭제하기

  1. 매치광 앱을 열고 로그인합니다.
  2. 우리 팀 탭 → 오른쪽 위 내 정보로 갑니다.
  3. 맨 아래 회원 탈퇴를 누르고 확인합니다.

진행 중인 매치(구장비 입금 대기, 확정, 노쇼 신고 확인 중)가 있으면 경기가 끝나거나 매치를 취소한 뒤 탈퇴할 수 있습니다.

앱 없이 삭제 요청하기

앱을 지웠거나 로그인할 수 없으면 nalho.service@gmail.com으로 아래 내용을 보내 주세요. 본인 확인 후 10일 안에 삭제하고 회신합니다.

  • 제목: 매치광 계정 삭제 요청
  • 로그인 방법 (카카오 또는 Apple)
  • 앱에 표시된 이름과 팀 이름

삭제되는 정보

  • 이름, 카카오·Apple 로그인 식별자, 앱 푸시 토큰: 바로 삭제
  • 구장비 받을 계좌 (팀 정보와 지난 매치에 남은 것 모두): 바로 삭제
  • 팀 대표 정보와 팀 소개: 바로 삭제, 모집 중인 글은 마감되고 대기 중인 신청은 취소됩니다
  • Apple로 로그인한 경우 Apple 로그인 연결도 끊습니다

남는 정보와 보관 기간

  • 팀의 지난 경기 결과, 매너 평가, 노쇼 기록: 상대 팀 기록 보존과 노쇼 방지를 위해 대표 정보를 지운 상태로 남습니다 (팀 이름 뒤에 "(탈퇴)" 표시). 이 기록만으로는 특정 개인을 알아볼 수 없습니다.
  • 채팅 메시지: 경기 예정 시각이 끝나고 90일 뒤 자동 삭제
  • 앱 안 알림함: 30일 뒤 자동 삭제
  • 접속 기록: 「통신비밀보호법」에 따라 3개월 보관 후 삭제

같은 카카오·Apple 계정으로 다시 로그인하면 새 회원으로 시작합니다.
